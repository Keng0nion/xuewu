これは何か

イグルー（中国語名・雪屋）は、あなたと友だちのパソコンの上で動く秘密のチャットルームです。プラットフォームも、アカウントも、「公式サーバー」もありません。自分のパソコンで部屋を開き、Tor のオニオンサービスで隠します。友だちは、あなたが個別に送ったカードと「いまのパスワード」で入室できます。すべてエンドツーエンド暗号化——ホストのパソコンでさえ暗号文を転送するだけ。アプリを閉じれば、部屋も会話も一緒に消えます。

部屋はホストのパソコンの上に

サードパーティのサーバーも、プラットフォームの裏側もありません。ホストがアプリを開いている間だけ部屋は存在し、閉じれば雪のように消えます。

Tor オニオンサービスで直結

お互いの IP は見えず、ネットワーク上の傍観者には「誰かが Tor を使っている」としか見えません。別々のネットワーク（大学・テザリング・自宅）からでも入れます。

エンドツーエンド暗号化

メッセージを読めるのは部屋の中の人だけ。ホストのパソコンも暗号文を転送するだけで、他人の内容は読めません。

二つの扉：カード + 5 分パスワード

入室には「個別に送ったカード」と「いまホストの画面に出ているパスワード」（5 分ごとに切り替え）の両方が必要です。追い出し = 鍵の交換：古いカードはその瞬間に無効になります。

使ったら消える

メッセージはメモリだけに存在し、ディスクには書きません。15 分で自動的に消え、部屋を閉じれば全員の内容がまとめて消去されます——「チャット履歴」というものはありません。

漏洩対策セット

画面録画系のアプリを検知すると、チャット領域が一瞬で雪の画面になります。画面には見ている本人の透かし。誰かがコピーすれば、部屋の全員に伝わります。

正直な限界

ここに並ぶ「できないこと」は、すべて実機テストの結論です。このアプリの性格そのものなので、トップページに置いています。

防げること

  • 通信事業者・ネットワーク層の盗聴（内容はエンドツーエンド暗号化）
  • プラットフォーム・ホスティング事業者・サーバー裏側（そもそも存在しません）
  • メンバー同士の IP 追跡（Tor オニオンサービス）
  • 部屋を探す見知らぬ人（カード + ローテーションするパスワードの二つの扉）
  • パソコンを何気なく覗く人（閉じたイグルーは記録を残しません）

防げないこと

  • 管理者権限・カーネルレベルの監視（どんなソフトにも防げません）
  • スマホでの撮影・外付けカメラ（透かしで事後にたどるしかありません）
  • 部屋の中の人の意図的な漏洩（透かしとコピー通知は抑止と追跡であって、防止ではありません）
  • すでに侵入されている端末
  • 「どんな方法でも監視できない」——この言葉は約束しません

実際にできたことだけを、約束に書きます。

3 ステップで始める

登録もサーバーも不要——イグルーを入れたパソコンが 2 台あれば十分です。

01ホスト：部屋を作る「部屋を作成」を押して Tor のブートストラップを待ちます（数十秒〜数分。ネットワーク次第）。部屋は専用の .onion アドレスを持ちます。
02「カード + いまのパスワード」を渡すカードを個別に送り、ホストの画面に出ている 5 分ごとに変わるパスワードを伝えます。両方そろって初めて入れます。
03入室して話す友だちはカードを貼り付け、パスワードを入力して入室。15 分でメッセージは溶けて消え、部屋を閉じれば全員の内容がまとめて消去されます。

よくある質問

なぜそんなに待つのですか（「Tor 接続を確立中」）？

Tor はまず回線を選び、ネットワーク情報をダウンロードする必要があります。初回のブートストラップは通常数十秒〜数分かかり、固まっているわけではありません。待機画面には実際に起きている段階（Tor 接続 → 部屋に接続）が順に表示され、3 秒を超えると「キャンセル」も出ます。

部屋につながらないときは？

よくある原因は二つ：① パスワードの期限切れ（5 分ごとに変わるので「いまの」を聞いてください）② ホストが部屋を閉じた、または一時的なネットワークの不調。画面はどちらなのかを正直に表示し、つながっているフリはしません。

本当に「監視されない」のですか？

その言葉は約束しません——どんなソフトにもできません。イグルーがすることは二つ：ネットワーク層の監視を防ぐこと（エンドツーエンド暗号化 + Tor）と、端末側でできる範囲の点検（画面録画・遠隔操作・自動起動項目。怪しければ知らせます）。相手の監視が OS の最下層に入っている場合や、管理者権限を持っている場合は、どんなソフトでも防げません。イグルーも同じです。

データを収集しますか？

テレメトリも更新チェックもクラウドもゼロ。Tor プロセスとの通信を除けば、アプリは一切ネットワーク要求をしません。ディスクへの唯一の書き込みは「言語設定」一行（0600）です。メッセージ・鍵・カードはすべてメモリだけに存在し、閉じれば消去されます。自分で確認できます：イグルーを閉じたあと、~/Library/Application Support/雪屋（言語設定の一行だけ）と /tmp の xuewu* ファイル（何も残っていません）を見てください。私たちの残留チェックツールでは 266 ファイルでキーワード 0 件でした。

何に使えますか？

プライベートな連絡に：友だち同士、家族、内緒にしたい相談。お住まいの地域の法律は守ってください。
